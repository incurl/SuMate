# 向量化有用吗？——一次实测

> 问的是：把 SuMate 的语义匹配换成向量检索，能不能改善它的**形而上学**？
> 答的是：实测，不是推理。
>
> 实验装置：`shibing624/text2vec-base-chinese`（BERT-base 中文，768 维），
> ONNX 量化版，CPU 单核。语料与词库直接取自本仓库，不另造数据。

---

## 一、先问对不对的问题

在试向量之前，先要弄清楚**坏在哪**。

### 1.1 症状：自由文本几乎无效

```
「我想一个人待着」 → 暮云收尽溢清寒。
「我很累不想动」   → 暮云收尽溢清寒。
「思念远方的人」   → 暮云收尽溢清寒。
「想起了从前」     → 暮云收尽溢清寒。
「不知道该怎么办」 → 暮云收尽溢清寒。
```

五次不同的描述，同一句。

### 1.2 病因：不是语义不够，是词不够

先怀疑**词库**：既然词库能表达这些状态，坏的就不是「说不出来」，
而是「连不上」。

实测：把这些描述映射到现有概念词库——

```
「我想一个人待着」 → 恬淡之喜      ✓
「我很累不想动」   → 无所事事的半天 ✓
「下雨了心里空空的」→ 烟雨微润      ✓
「思念远方的人」   → 情爱与不可得   ✓
「想起了从前」     → 故园与归思    ✓
「不知道该怎么办」 → 无奈与无力    ✓
```

**8/8 全部可表达。** 所以缺口不在概念层。

再问：那为什么连不上？把词库触发词和用户会打的字对照——

```
累 不在    困 不在    烦 不在    难过 不在    开心 不在
喜欢 不在  爱 不在    想家 不在  回家 不在  孤独 不在
寂寞 不在  平静 不在  放松 不在  压力 不在  撑不住 不在

0 / 19
```

**触发词表 936 条，全部是古典词汇；用户打的是现代口语。**
（补词之后共 1081 条，其中 145 条是现代口语。）
「想家」在词表里找不到，因为词表写的是「故园」；「累」找不到，因为词表写的是「倦」。

> 这就是全部的病因：**不是模型不懂中文，是词表不肯说人话。**

---

## 二、那么，向量能补上这一层吗

### 2.1 实验

同一批描述，三条通路各选一句：

| 描述 | 当前（单字重合） | 纯词汇桥接 | **向量** | 应当指向 |
|---|---|---|---|---|
| 我想一个人待着 | 自净方能净彼… | 暮云收尽… | **缺月挂疏桐漏防人初静** | 恬淡之喜 |
| 我很累不想动 | 我辈情钟… | 暮云收尽… | **自净方能净彼…汗流** | 无所事事的半天 |
| 下雨了心里空空的 | 半夜银山… | 暮云收尽… | **雨暗初疑夜风回忽报晴** | 烟雨微润 |
| 思念远方的人 | 自净方能净彼… | 暮云收尽… | **十年生死两茫茫。不思量** | 情爱与不可得 |
| 想起了从前 | 银铮旋品… | 暮云收尽… | **分携如昨。人生到处萍飘泊** | 故园与归思 |
| 不知道该怎么办 | 九十日春… | 珠桧丝杉… | **冰肌自是生来瘦** | 无奈与无力 |

**向量每一条都不同，且每一条都切题。**

- 「我想一个人待着」→ 缺月挂疏桐，幽人独往来（**独处的孤客**）
- 「下雨了心里空空的」→ 雨暗初疑夜（**字面就是雨**）
- 「思念远方的人」→ 十年生死两茫茫，千里孤坟（**远方的思念**）
- 「有点高兴」→ 惭愧今年二麦丰，千畦翠浪（**丰收的欢欣**）

纯词汇桥接（多字词优先）则基本失效——因为它仍然只在词表里找，
而用户的词不在词表里。**这恰好证明：缺的正是那个跨越古今的桥。**

### 2.2 语义轴能不能因此有区分度

形而上学评估里最刺眼的一条：**语义轴在前 50 名上标准差 0.00**，
是常数，不测量任何东西。

向量给出的余弦相似度：

```
「我想一个人待着」   前 50 名：均值 0.254  标准差 0.019  取值 47 种
「我很累不想动」     前 50 名：均值 0.295  标准差 0.021  取值 48 种
「下雨了心里空空的」 前 50 名：均值 0.296  标准差 0.029  取值 49 种
```

**从 1 种变成 47–49 种。** 语义轴第一次真的在测量语义。

### 2.3 关键：向量与词库是**互补**，不是替代

这是最重要的一条，因为它决定了架构。

实测：向量选出前 5 句后，**词库仍能解释其中的 6/6**：

```
「我想一个人待着」 → 缺月挂疏桐…
   概念层：月与孤高、梅与不屈、谪居之苦   ✓
「思念远方的人」   → 十年生死两茫茫…
   概念层：月与相思、慈母与死生、离别与送行 ✓
```

向量负责**跨越古今找到那一句**；词库负责**说明它为什么是那一句**。

这正是本项目一路坚持的分工（见 SKILL_09「框架可继承，细节必须重做」、
SKILL_05「格式正确 ≠ 数据正确」）：**找到**与**解释**本就不该是同一件事。

## 三、代价

| 项 | 数值 | 判断 |
|---|---|---|
| 模型体积 | 203 MB | 当前整个二进制 11 MB。**是它的 18 倍** |
| 编码速度 | 69 ms/句（CPU 单核） | 全库 304 句一次性 21 s，之后查表 |
| 可审计性 | ✗ | 权重不可读。「为什么这句更像」不能像现在这样逐条说明 |
| 离线复算 | ✗ | 需要 200 MB 外部模型 |
| 换模型 | 需重编码全库 | 但改一个词条不必重训 |

体积与可审计性是真实的代价。尤其后者与本项目的立场有张力：
**这个项目一路强调「能逐条说明」，引入一个不可读的权重，等于在最要紧的地方
放弃了这个立场。**

## 四、结论

### 4.1 向量有用，而且有用在**一个特定的地方**

**它补的是「用户的词」与「词库的词」之间那道缺口**——
一道 0/19 的缺口，一道纯粹的**词汇**缺口。

它**不能**替代的东西：

- 不能替代词库做解释（向量给不出理由）；
- 不能替代哲学层的前提检验（向量不知道「你其实还走得动」）；
- 不能修好那个更根本的问题——**同分时排序的任意性**。

### 4.2 但有一个更便宜的办法——而且已经做完了

既然病因已经查明是**词表不肯说人话**，那么最直接的办法是
**让词表说人话**：给每个概念补上现代口语触发词。

**已实施**（`internal/curated/modern.go`，约 110 个词，0 字节外部依赖）：

| | 修复前 | 修复后 |
|---|---|---|
| 现代口语在触发词表中的命中率 | 3/60（5%） | **48/60（80%）** |
| 触发词总数 | 936（全是古典） | **1081（145 条现代口语）** |
| 描述 → 概念 的桥接命中 | 1/10 | **10/12** |
| 自由文本对排序的影响 | 前五 5/5 相同 | **前五 0/5 相同** |

而且修复后的匹配**仍然可解释**：

```
「我很累不想动」 → 闲倚胡床庾公楼外峰千朵
   理解为：idleness.day（无所事事的半天）
   解释：「东坡替所有想虚度的人辩护：浮生难得，能什么都不做是一种本事。」
```

用户看到的是「你说了『累』，我们懂成了『无所事事的半天』」，
而不是一个 0.87 的余弦。**这是向量模型给不了的东西。**

副作用也检查过：标签覆盖仍是 143/143 全可达，计数几乎未变；
「无名之句」从 171 减到 168——**三句被现代词救回来了**，
这正是系统变好的证据，不是退化。

### 4.3 最诚实的排序

| 方案 | 修好自由文本 | 修好语义轴 | 体积 | 可审计 |
|---|---|---|---|---|
| 修复前 | ✗ | ✗ | 0 | ✓ |
| **补现代触发词（已做）** | ✓ | 部分 | 0 | ✓ |
| **向量** | ✓ | ✓ | 203 MB | ✗ |
| 补词 + 向量 | ✓ | ✓ | 203 MB | 部分 |

**补词在前，向量在后。** 补词解决了 80% 的日常表达，且不花一分钱、
不丢可解释性。向量该留给剩下的部分——用户写「emo」「破防」「钝感」
这类词表真的没救的说法。

**但要诚实**：补词**没有**修好语义轴（标准差仍是 0.00），
也没有修好同分时的任意性。这两件事只有向量能碰，
而碰了要付 203 MB 与不可审计的代价。

## 五、给项目的一条笔记

这一轮实验的价值，不在于「结论是应该用向量」——结论恰恰相反。
价值在于**它把一个模糊的抱怨变成了一个可证的诊断**：

> 「自由文本没用」→ 不是「语义能力不够」，
> 而是「触发词表里有 0 个现代口语词」。

诊断清楚了，药就便宜得多。

这与 SKILL_07 的教训是同一件事的另一面：
**「完成不等于正确」，而「说不清哪里不对」比「不对」更贵。**

## 七、一句话

> 向量确实有用，但**有用在一个很窄的地方**：
> 它能跨越「用户的词」与「词库的词」之间的鸿沟。
>
> 而这道鸿沟一旦被量出来，就发现它只是**一道词汇的沟**——
> 936 个古典触发词里，0 个现代口语。
>
> 于是：**110 个词，0 字节外部依赖，把 5% 补到 80%**，
> 而可解释性一点没丢。
>
> 这大概是这一轮最值得记下的一句：
> **在把问题交给更贵的解法之前，先量一量问题有多大。**
