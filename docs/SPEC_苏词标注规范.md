# SuMate（东坡嘴替）苏词标注规范

> 版本：`sumate-ci-semantic-v1`
> 适用文本：`东坡词.txt`（钦定四库全书《东坡词》，728 行 / 83,257 字）
> 参考体系：`../oblique` 的《楹联丛话全编》语义标注工程（**框架继承，细节重做**）

---

## 一、目标与原则

把一部三千余字的苏词总集转化为**可检索、可匹配、可二次开发**的结构化语料，
同时保持原文可读、可回溯。

六条原则：

1. **只加标记，不改原文**。任何清洗都不得改变词句本身；缺文只**计数**，不**补字**。
2. **底本分层**。原文、校语、异文、缺文必须分开，不得揉进词句。
3. **内容与样式分离**。标注是轻量 JSON 字段，渲染交给前端。
4. **结构可引用**。每首、每句、每个匹配单元都有稳定 ID。
5. **词句是一等公民**。以「单句」与「对称联」为最小检索粒度。
6. **标注层只提取文本中确定存在的信息**；需要外部知识（格律、韵书）的判断留给分析层。

## 三、底本分层

四库正文里 `【…】` 不是词句。四种情形，**按顺序剥**：

| 层 | 形态 | 处理 |
|---|---|---|
| 缺文 | `【原缺】`、`【阙】` | **计数**，记入 `lacunae`，**不补字** |
| 作者 | `【吴融】`（集句所引诗人） | 记入 `quotes`，据此判定 `kind=jiju` |
| 异文 | `【一作来】`、`【一作潺潲】` | 剥离，不计入字数 |
| 校语 | `【惠州梅花上珍禽曰…】` | 剥离，不计入字数 |

**顺序不可颠倒**：作者标记必须在「剩余括号」那一步之前读取，否则集句永远
识别不出来。

`kind` 取三值：`normal` / `jiju` / `lacuna`。

## 四、结构层：稳定编号

| 层级 | 示例 | 含义 |
|---|---|---|
| 全集 | `sumate` | 《东坡词》 |
| 词牌 | `水调歌头` | 词的曲调 |
| 词 | `水调歌头-u6e2au79cb-0007` | 一首词（词牌 + 序号） |
| 句 | `…-0007-003` | 一个最小匹配单元 |

单元有两种：

- `line`：一个单句；
- `couplet`：一对对称的句子（按字数差 ≤ 1 判定）。

## 五、语义层：概念词典

45+ 个概念，把古典意象翻译成机器可读的单位。每个概念带：

| 字段 | 含义 |
|---|---|
| `key` | 稳定键，如 `moon.longing` |
| `name` | 中文名，如「月与相思」 |
| `surface` | 表层义 |
| `deep` | 深层意境 |
| `philosophy` | 哲理内涵 |
| `attitude` | 对世的态度 |
| `polarity` | 极性：positive / neutral / melanchol / mixed |
| `emotions` | 情绪键 |
| `tangents` | 东坡气质 |
| `tags` | 标签树节点 |
| `keywords` | 触发词 |

### 5.1 触发词的强弱（Y11）

触发词分两级：

- **具体词**（≥2 字，如「拣尽寒枝」「婵娟」）：强证据，单凭即可成立；
- **普通字**（1 字，如「风」「月」「无」）：弱证据，只出现在三成以上语料里，
  不得单独成立。

因此 `Annotation.Concepts`（全部命中）与 `Annotation.Primary`（有具体词支撑的
命中）分列：**Primary 决定文字解读，Concepts 决定标签覆盖**。

### 5.2 词表纪律（Y4–Y5）

- 词表的质量取决于**剔除了多少**，而不是收了多少；
- 与普通词同形的词，靠**长词优先**解决；解决不了才进黑名单；
- 「看起来像」的字眼必须逐条查证，不能批量处理（Y3b）。

## 六、情感层

四个维度，每维情绪均分四级强度（slight / moderate / obvious / profound）：

| 维度 | 说明 |
|---|---|
| `positive` | 正面：恬静之喜、闲适从容、肆意洒脱、豁达大度、如释重负、安宁平静、仍有希望、温柔亲和、风流闲适、人间烟火的从容、平淡知足 |
| `neutral` | 中性哲思：人生洞见、世事观察、冷静超脱、理性思考、平淡知足、不萦于物、宁静独处 |
| `melanchol` | 低回疗愈：轻微孤独、淡淡怀旧、遥远想念、淡淡的窝心、仕途之叹、离别之悲、人生无奈、琐碎疲惫 |
| `dongpo` | 东坡气质：悲而能超、苦中作乐、与不完美和解、挫败后的豁达、超越功名执念、平静接受命运 |

强度由命中概念数决定：1 → slight，2 → moderate，3 → obvious，≥4 → profound。

## 七、哲学层

情绪与气质都只是「怎么感觉」，哲学层回答的是「**怎么活**」。

### 7.1 三者的分工

| 层 | 问的问题 | 例 |
|---|---|---|
| 情绪 | 我现在是什么感觉 | 遥远想念 |
| 气质 | 苏东坡怎么扛住这件事 | 悲而能超 |
| **立场** | 他认为应当怎么活 | **有些事不是你不努力** |

### 7.2 立场的四个字段

每个立场带四样东西：

- `claim`：**主张**——这句词在断言什么；
- `premise`：**前提**——要让它成为安慰，读者必须处在什么位置；
- `shadow`：**影子**——前提不成立时，它变成什么；
- `earned`：**何以说得出**——苏东坡写这句话时经历过什么。

### 7.3 为什么要「影子」

「此心安处是吾乡」对一个已无别处可去的人是安慰，对一个还走得动的人是
**不走的理由**。同一句词，落在不同的人身上，是两回事。

因此产品不把安慰无条件交出去：它检验前提，并说明前提不在时会变成什么。
这是「嘴替」与「引用」的区别——嘴替要知道**这一句此刻是不是在对你说**。

### 7.4 立场如何被检验

立场的 `supports` 与 `undermines` 列出满足／违反前提的标签；系统只根据
**用户实际选中的标签**判断，不做额外推断。结果分四档：

| 档 | 含义 |
|---|---|
| `held` | 前提成立，这一句是站在他位置上说的 |
| `strained` | 勉强成立，只剩一半意思 |
| `unknown` | 说得不够，还看不出 |
| `failed` | 前提不成立，这一句未必是给他的 |

`failed` 的句子会被**降权但仍然展示**，并附上它自己的影子。

### 7.5 确信度

匹配分高只说明**它符合标签**；「是不是那一句」要看两样东西：**与次优的
差距**（差得少说明只是勉强领先）与**用户说得多具体**。二者分报。

### 7.6 产品自己的立场

产品也要交代自己的前提、自己的失效方式，以及**找不到时怎么办**。
见 `internal/curated/product.go`，并在界面上公开显示。

## 八、无名之句（系统边界的去处）

有 171 句没有被任何概念命中。它们拿不到标签，因此进不了标签树，也从不出现于
匹配结果——在界面上等于不存在。

规范上把它们**单独成架**，而不是丢弃或硬塞：

| 组 | 判据 | 句数 |
|---|---|---:|
| 长度如常，而未有名 | CJK ≥ 8 | 17 |
| 偏短，意象未成形 | 5 ≤ CJK < 8 | 98 |
| 太短，无以名之 | CJK < 5 | 56 |

### 8.1 为什么按长度分组，而不是按「完整度」

「是否完整」是判断，「是否五字」是事实。按事实分组，书架就是**诚实的**；
按判断分组，就会把「一舸姑苏。」说成「句子完整，意思清楚」，那是假的。

### 8.2 「疑讹」是提示，不是判决

含全语料仅出现一次的字，会带一个 `suspect_glyph` 提示。
但**罕见字不等于讹字**：鹅、禹、尹、睢盱都罕见而正确。
真正需要人判的是那些既罕见、读来又不通的（如「魂防」当作「魂断」）。

> 这一条是踩出来的：初版把「金钗玉碗泻鹅黄」判为疑讹，
> 而它字字清楚。**形式上的异常不能替代读一遍。**

## 九、标签层

五个根维度，143 个节点，4 层：

| 根 | ID | 含义 |
|---|---|---|
| 当前心境与内在情绪 | `mood` | 说不出口的那种感觉 |
| 当前地点与周遭环境 | `place` | 你此刻站在哪里 |
| 当前时辰、节令与天气 | `weather` | 此刻的天与时 |
| 人际关系与社交状态 | `relation` | 你与谁之间的事 |
| 人生境遇与现实处境 | `occasion` | 人生的哪个路口 |

**过滤语义**：路径上的每一个节点都必须命中（**交集**）。因此在某一维度里
越挖越窄；换维度则继续收窄。

**词牌↔字数是可自动检查的领域约束**，是本项目的「楹联等长」。

## 十、校验

### 10.1 第一层：格式（五项）

1. **底本完整性**：校语、异文不得留在词句里；
2. **括号配对**：`【】` 数量相等；
3. **无嵌套**；
4. **无半角引号**；
5. **类型白名单**：只允许已知标注符号。

### 10.2 第二层：领域（三项）

1. **词牌字数**：与同词牌的众数偏差 > 4 字即须检查；
2. **句读归属**：每句以句读收尾；
3. **最小单元非空**：无空句。

### 10.3 质量门

```
格式校验 5/5 通过   ← tools/lint_corpus.py
领域校验 3/3 通过   ← 同上 + go test ./internal/corpus/
```

**任何改动后这两组数字都必须仍然成立，否则不许提交。**

## 十一、已知限制

1. **实体标注是词典 + 规则驱动，不是全量 NER**。冷僻地名、隐喻仍有漏标。
2. **不做格律校验**。平仄、押韵需要《平水韵》，且假阳性高（集句常有意拗句）。
   数据已含句读与字数，研究者自行接韵书即可。
3. **作者字段是线索，不是考证结论**。`wellKnownPoems` 表中的年代与地点为通行
   说法，个别词题存疑。
4. **概念覆盖是稀疏的**。约 12% 的词没有命中任何具体概念（560 个具体触发词
   覆盖 267/304 首）——它们仍然可被检索，但没有语义解读。
5. **四库本有缺漏**。毛晋刻本未收《定风波·竹杖芒鞋》《虞美人·春花秋月》
   等名篇，语料忠实于底本，不补他本。
6. **干支年表按苏轼生平（1037–1101）截取**。早年作品若用干支纪年，可能匹配
   到较晚的同名干支。
